# BookFlow AI

سامانه ترجمه کتاب‌های انگلیسی به فارسی، با رابط موبایل‌پسند و اجرای محلی.

## نسخه جدید آزمایشی: BookFlow AI 2

نسخه جدید در شاخه `bookflow-v2` قرار دارد و از لپ‌تاپ ویندوز به‌عنوان سرور محلی استفاده می‌کند. می‌توانی با گوشی، در همان شبکه Wi-Fi، وارد رابط برنامه شوی.

**راهنما:** [راهنمای فارسی نصب و اجرا](mobile-server/README_FA.md)

**فایل اجرا در ویندوز:** [start_windows.bat](mobile-server/start_windows.bat)

## امکانات فعلی نسخه ۲
- ترجمه PDF متنی به فارسی
- Gemini، OpenAI، xAI و OpenRouter
- تقسیم متن و شناسایی مقدماتی فصل‌ها
- ذخیره مرحله‌ای ترجمه و ادامه پس از توقف
- واژه‌نامه اختصاصی
- خروجی Word راست‌چین

## محدودیت‌های نسخه آزمایشی
OCR فایل اسکن‌شده، حفظ کامل چیدمان PDF، تصاویر و پاورقی‌ها هنوز پیاده‌سازی نشده‌اند. این نسخه برای استفاده شخصی در شبکه محلی است و نباید مستقیماً روی اینترنت عمومی منتشر شود.
