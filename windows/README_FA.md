# BookFlow AI — نسخه ویندوز

این پوشه نسخه دسکتاپ محلی BookFlow AI است؛ نسخه موبایلی آزمایشی در ریشه مخزن جداگانه باقی مانده است.

## پیش‌نیازها
- Windows 10/11 نسخه ۶۴ بیتی
- Python 3.11 یا 3.12 نسخه ۶۴ بیتی
- اینترنت برای نصب وابستگی‌ها و اتصال به Gemini

## نصب و اجرا
1. مخزن را دانلود و از حالت ZIP خارج کنید.
2. Python 3.11 یا 3.12 را نصب کنید و گزینه Add Python to PATH را فعال کنید.
3. وارد پوشه windows شوید.
4. فایل install.bat را اجرا کنید.
5. پس از نصب، start.bat را اجرا کنید؛ برنامه در مرورگر باز می‌شود.

## کلید Gemini
از Google AI Studio کلید API بسازید: https://aistudio.google.com/app/apikey
کلید را فقط در کادر برنامه وارد کنید؛ در فایل‌ها یا GitHub قرار ندهید.

## استفاده
PDF متنی انگلیسی را در زبانه «پروژه جدید» بارگذاری کنید، پروژه را بسازید و در زبانه «پروژه‌ها و ادامه کار» ترجمه را در نوبت‌های کوچک انجام دهید. هر بخش پس از ترجمه در پایگاه داده محلی ذخیره می‌شود و پس از بستن برنامه قابل ادامه است. خروجی Word قابل ویرایش است.

## ذخیره‌سازی و محدودیت‌ها
- داده‌ها در پوشه windows/bookflow_data ذخیره می‌شوند؛ از این پوشه پشتیبان بگیرید.
- فقط PDF متنی پشتیبانی می‌شود؛ OCR در این نسخه وجود ندارد.
- تصاویر، جدول‌ها، نمودارها و صفحه‌آرایی اصلی PDF حفظ نمی‌شوند.
- سهمیه رایگان Gemini تضمین‌شده یا نامحدود نیست و ممکن است تغییر کند.
- متن کتاب برای ترجمه به Gemini ارسال می‌شود؛ سیاست داده و حریم خصوصی سرویس را پیش از استفاده بررسی کنید.
- خروجی باید پیش از انتشار توسط مترجم/ویراستار انسانی بازبینی شود.
