# BookFlow AI — نمونه اولیه موبایلی

## این نسخه چه می‌کند؟
- در مرورگر اندروید اجرا می‌شود.
- PDF متنی را باز می‌کند و متن صفحات را استخراج می‌کند.
- متن را در بخش‌های کوچک به Gemini API می‌فرستد.
- ترجمه را در فایل Word فارسی ذخیره می‌کند.

## محدودیت‌های مهم
- این نسخه نمونه اولیه است، نه محصول نهاییِ آماده انتشار.
- PDF اسکن‌شده/OCR، حفظ تصاویر و جدول‌ها، تشخیص خودکار فصل‌ها، حافظه اصطلاحات، مقابله مستقل ترجمه با اصل و ادامه مطمئن پس از قطع اتصال هنوز پیاده‌سازی نشده‌اند.
- کلید API در درخواست مرورگر استفاده می‌شود؛ برای استفاده شخصی و آزمایشی است. برای انتشار عمومی باید یک واسط سروری امن ساخته شود تا کلید در مرورگر کاربران افشا نشود.
- سهمیه رایگان Gemini تضمین‌شده یا نامحدود نیست. قبل از ترجمه کتاب کامل، یک نمونه کوتاه آزمایش کن.
- خروجی باید حتماً توسط مترجم انسانی بازبینی شود.

## اجرا
برای تست ساده روی رایانه، پوشه را با یک وب‌سرور محلی اجرا کن؛ بازکردن مستقیم فایل HTML ممکن است برخی قابلیت‌ها را محدود کند.
برای نصب به‌صورت PWA روی گوشی، فایل‌ها باید روی یک میزبان HTTPS قرار بگیرند. سپس آدرس سایت را در Chrome باز کن و از منوی سه‌نقطه گزینه Add to Home screen / Install app را بزن.

## شروع کار
1. فایل‌ها را روی یک فضای میزبانی HTTPS قرار بده.
2. در گوشی آدرس سایت را باز کن.
3. API Key را فقط در دستگاه خودت وارد کن.
4. یک PDF متنی کوچک (۱ تا ۳ صفحه) انتخاب و آزمایش کن.
5. پس از بررسی کیفیت و مصرف سهمیه، سراغ کتاب کامل برو.

## نکته حریم خصوصی
از بارگذاری آثار محرمانه یا منتشرنشده تا زمانی که شرایط پردازش داده در حساب و طرح API خود را بررسی نکرده‌ای خودداری کن.
