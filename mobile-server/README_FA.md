# راه‌اندازی BookFlow AI 2 روی ویندوز و استفاده با گوشی

## امکانات نسخه آزمایشی
- رابط فارسی و سازگار با صفحه موبایل
- بارگذاری PDF متنی و تقسیم خودکار به بخش‌ها
- انتخاب Gemini، OpenAI، xAI یا OpenRouter
- واژه‌نامه اختصاصی
- ذخیره هر قسمت ترجمه‌شده در SQLite و ادامه پس از توقف یا خاموش‌شدن برنامه
- خروجی Word با راست‌چین پایه
- کلید API در حافظه برنامه است و در پایگاه داده ذخیره نمی‌شود

## پیش‌نیاز
Windows 10/11 و Python 3.11 یا جدیدتر. هنگام نصب Python گزینه Add Python to PATH را فعال کن.

## اجرا
1. پوشه mobile-server را از مخزن دریافت کن.
2. روی start_windows.bat دوبار کلیک کن.
3. در لپ‌تاپ نشانی http://127.0.0.1:8000 را باز کن.
4. نشانی شبکه محلی چاپ‌شده در پنجره را در مرورگر گوشی باز کن. گوشی و لپ‌تاپ باید به یک Wi-Fi وصل باشند.
5. PDF را بارگذاری کن، سرویس و مدل را انتخاب کن، کلید API را وارد کن و ترجمه را شروع کن.

## امنیت
این نسخه برای شبکه محلی و استفاده شخصی است. سرور روی شبکه محلی در دسترس است و هنوز ورود با رمز عبور ندارد؛ در Wi-Fi عمومی اجرا نکن و پورت 8000 را روی اینترنت باز نکن. کلید API با بستن سرور از بین می‌رود؛ برای ادامه پس از راه‌اندازی مجدد، کلید را دوباره وارد کن.

## محدودیت‌ها
- PDF اسکن‌شده و OCR هنوز پشتیبانی نمی‌شود.
- شناسایی فصل‌ها فعلاً بر اساس عنوان‌هایی مانند Chapter 1 است.
- قالب‌بندی کامل صفحه، تصاویر، پاورقی‌ها و جدول‌های PDF حفظ نمی‌شود.
- هزینه و کیفیت ترجمه به سرویس و مدل انتخابی بستگی دارد.
- خروجی باید بازبینی انسانی شود.
